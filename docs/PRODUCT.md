# 弹线 Linebeat · 产品文档 v0.2

## 概括

一个 2D 重力沙盒音乐玩具：摆线段、放球、放发射器，球撞线就发出声音；线段和发射器的每个参数都可写成表达式。

## 基线要求


- 2D 重力场，无阻力，球与线段碰撞；线段端点位置可被表达式驱动 
- 用户自由放置：线段、球、发射器（位置 + 释放时机 + 初速度） 
- 线对象碰撞时的声音有音色、音高、力度等属性。音色目前使用 SF2
- 线属性：可见/可碰撞、音色、音高、力度 
- 球：位置 + 速度 + 可选半径
- 参数大多可为常量或函数 
- 确定性

## 撤销：两个栈 + 编辑存档

| 栈 | 内容 | 生命期 |
|---|---|---|
| A `doc` | 落到工程的编辑 | 常驻 64 步 |
| B `ball` | 暂停期间进行的所有球相关编辑 | 仅当次暂停期间有效 |

- 记录带递增 `seq`；暂停时 `Ctrl+Z` 比较两栈栈顶，撤销较新的。
- 运行中 `Ctrl+Z` 只看栈 A。
- 运行期进行球相关的编辑不可撤销，其不会落到工程
- 运行期进行线相关的编辑会落到工程
- **编辑存档模式**：进入即强制暂停 + 球回到初态 + 清空栈 B；此模式下放球/删球写 `project.balls` 并入栈 A。恢复运行即自动退出。

## 简洁 / 高级模式

- 简洁（默认）：工具条 + 画布 + 初级检查器（提供常用预设）
- 高级：表达式、世界参数、发射器细节、调试信息

## 音色

- 枚举当前 SF2 的全部 preset（bank 分组、真实音色名），可搜索下拉
- 「载入其它 SF2…」用文件对话框，voice 指向该文件
- 工程里只存 `{bank, program, file}`

## 多选 / 框选 / 复制粘贴

- 选择工具空白处拖动 = 框选；`Shift+点击` 加选；`Ctrl+A` 全选
- 拖动任一选中对象 = 整体平移（一次撤销）
- `Ctrl+C` / `Ctrl+V`：粘贴到鼠标位置，保持相对布局，重新分配 id
- 多选时检查器显示「N 个对象」+ 批量删除
